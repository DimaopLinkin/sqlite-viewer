# SQLite Viewer

Flutter-приложение для просмотра содержимого SQLite-файлов (только чтение).
В первую очередь macOS и Web, landscape. Папки `android/` и `ios/` сохранены на будущее.

## Возможности

- Открытие `.sqlite` / `.db` / любого SQLite-файла через системный диалог выбора файла.
- Слева список таблиц и представлений с количеством строк и поиском по названию.
- Справа таблица: закреплённая шапка и колонка номеров строк, горизонтальный и вертикальный скролл, изменение ширины колонок перетаскиванием границы.
- В каждой колонке фильтр (содержит, не содержит, равно, начинается/заканчивается, `>`, `<`, `IS NULL`, пусто и т.д.) и сортировка по клику на название (по возрастанию → по убыванию → без сортировки).
- Текстовый поиск регистронезависимый с поддержкой кириллицы.
- Клик по строке открывает диалог со всеми значениями: каждое можно выделить и скопировать, есть копирование всей строки в JSON и переход к соседним строкам (кнопки ↑/↓ или Alt+↑/↓).
- Правый клик по ячейке копирует её значение.
- Тёмная (по умолчанию) и светлая тема.

## Большие таблицы

Строки не загружаются в память целиком. Количество строк, фильтры, сортировка и страницы
выполняются SQL-запросами (`COUNT(*)`, `WHERE`, `ORDER BY`, `LIMIT/OFFSET`), в памяти держится
только текущая страница (50–1000 строк). Грид строит только видимые ячейки
(`TableView` из `two_dimensional_scrollables`).

- **macOS / нативные платформы:** файл читается напрямую с диска в режиме read-only, каждый запрос
  выполняется в фоновом изоляте (`Isolate.run`), UI не блокируется. WAL-базы, у которых рядом нельзя
  создать `-shm` (песочница macOS), открываются в режиме `immutable=1`.
- **Web:** файл читается в память браузера и открывается в WASM-сборке SQLite (`web/sqlite3.wasm`).
  Сам файл не изменяется.

## Сборка

Требуется Flutter 3.41.0 (Dart 3.11.0), версия зафиксирована в `.fvmrc`.

```bash
flutter pub get
flutter run -d macos
flutter run -d chrome
flutter build macos
flutter build web
flutter test
```

`package:sqlite3` 3.x подключает нативную библиотеку SQLite через build hooks: при первой нативной
сборке она скачивается автоматически, ставить SQLite в систему не нужно.

`web/sqlite3.wasm` взят из релиза [`sqlite3-3.5.2`](https://github.com/simolus3/sqlite3.dart/releases/tag/sqlite3-3.5.2)
и должен соответствовать версии `sqlite3` в `pubspec.lock`. При обновлении пакета обновите и файл.

## Структура

```
lib/
  data/    модели, построение SQL, чтение SQLite (общий код + нативная и web-реализации)
  state/   ViewerController (файл и список таблиц), TableController (фильтры, сортировка, страницы)
  ui/      сайдбар, грид, шапка колонок, пагинация, диалог строки, тема
test/      тесты SQL-слоя, форматирования и виджет-тесты основных сценариев
```
